# AI 3D Design Studio

## Product Vision

Build a browser-based AI 3D design application that allows non-technical users to create and modify Blender scenes using natural language.

The user should not need to understand:

- Blender
- Python
- MCP
- terminals
- rendering configuration
- infrastructure

The user interacts through a browser.

## Core User Experience

A user can:

1. Log in.
2. Open or create a design project.
3. Upload plans, reference photos, and design assets.
4. Chat naturally with an AI design agent.
5. View the current 3D project.
6. Ask for modifications.
7. See modifications happen in Blender.
8. View quick previews.
9. Generate high-quality renders.
10. Continue a project later without losing context.

Example:

User:
"Move the kitchen island 40 cm toward the window."

System:

- understands the request
- inspects the Blender scene
- finds the island
- checks constraints
- moves it
- saves the project
- generates a preview
- reports the result

## Long-Term Capabilities

The platform should eventually support:

- multiple users
- multiple projects
- multiple sessions per project
- persistent project memory
- reference images
- architectural plans
- interactive 3D preview
- browser object selection
- quick rendering
- photorealistic final rendering
- voice interaction
- annotations
- before/after comparison
- undo and version history
- multiple Blender workers
- multiple GPUs
- collaborative projects
